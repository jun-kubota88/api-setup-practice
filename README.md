## 概要
COACHTECH 教材 Tutorial 11-1「API開発環境の構築と疎通確認」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- REST API（JSONレスポンス）
- Postman（動作確認）

## 学んだこと
- REST API の基本概念（リソース、HTTPメソッド、ステータスコード）
- Laravel での API ルート（routes/api.php）の書き方
- Postman を使った API リクエスト送信とレスポンス確認
